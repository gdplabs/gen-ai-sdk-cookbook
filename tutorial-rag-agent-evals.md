# Evaluate Your RAG Chatbot

This guide will walk you through evaluating a RAG pipeline's performance using GL SDK's evaluation module. You'll learn how to measure the quality of responses generated by your chatbot against expected answers.

## The Usecase: Imaginary Animals Researcher

Imagine you are building a chatbot for a researcher studying **Imaginary Animals**. The researcher needs accurate information about nocturnal creatures. We need to evaluate if our RAG pipeline correctly identifies these creatures and provides grounded responses.

## 1) Agent Usage Pattern

Before running the RAG pipeline, it's helpful to understand the basic usage pattern for local agents in GL SDK. Local agents run entirely on your machine without needing a server deployment.

{% code title="pipeline.py" lineNumbers="true" %}
```python
from glaip_sdk.agents import Agent

# Create and run locally (no deploy needed)
agent = Agent(
    name="local-agent",
    instruction="You are a helpful assistant.",
)

# Runs immediately on your machine
response = agent.run("Hello!") 
```
{% endcode %}

## 3) Customize the Evaluation

The core logic resides in `pipeline.py`. To evaluate your own specific use case, there are key areas you might want to modify.

### Define your Test Case

In `pipeline.py`, you can modify the `QUERY` and `EXPECTED_OUTPUT` to match the specific facts you want to test.

{% code title="pipeline.py" lineNumbers="true" %}
```python
# 💡 MODIFY THESE for your specific test case
QUERY = "Give me nocturnal creatures from the dataset"

EXPECTED_OUTPUT = (
    "The nocturnal creatures in the dataset include the Luminafox, "
    "Dusk Panther, Gloombat, Moonstalker, and Glowhopper. "
    "They inhabit various dark environments such as caverns, twilight forests, "
    "and nocturnal plains, and exhibit traits like bioluminescence, echolocation, "
    "and stealth."
)
```
{% endcode %}

### Choose your Judge Model

The evaluation uses a "Judge" model to score the results. You can change this to any model supported by the SDK.

{% code title="pipeline.py" lineNumbers="true" %}
```python
# 💡 MODIFY the model ID to use a different judge
judge_model = build_lm_invoker(
    "google/gemini-3-flash-preview", # You can use gpt-4o, etc.
    os.getenv("GOOGLE_API_KEY"),
)
evaluator = GEvalGenerationEvaluator(models=judge_model)
```
{% endcode %}
