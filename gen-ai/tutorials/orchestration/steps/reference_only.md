# Steps | GL SDK Orchestration

This page is a reference overview of step types: `step`, `transform`, `bundle`, `copy`, `if_else`, `switch`, `toggle`, `parallel`, `map_reduce`, `goto`, `no_op`, `terminate`, `guard`, `while_do`, `try_catch`, `interrupt`, `pause`, `log`, and `subgraph`.

Runable coverage for `pipeline/` remains the source of truth; this page is tracked as reference material until standalone step examples are verified in this worktree.
