## Getting Started

[uv](https://docs.astral.sh/uv/) manages the project environment. Install
dependencies using [`setup.sh`](./setup.sh) (Linux/macOS) or
[`setup.bat`](./setup.bat) (Windows).

## Usage

```bash
uv run rag_state.py
uv run custom_state.py
uv run pydantic_state.py
```

## Reference

These examples are based on the [GL SDK GitBook documentation for State](https://gdplabs.gitbook.io/sdk/gen-ai-sdk/tutorials/orchestration/state).
