# Classifier Router | GL SDK Orchestration

Classifier Router requires `gllm-pipeline[llmrouter]`, which pulls PyTorch and classifier model files such as `.pkl`/`.pt`. In this worktree, those artifacts are not installable/verifiable; `llmrouter-lib` is unavailable locally, so this entry is reference-only.
