# Composer | GL SDK Orchestration

Composer is a fluent API builder around `Pipeline(...)`. The GitBook page covers many chained forms (`when/then`, `if_else`, `switch`, `toggle`, `guard`, `parallel`, `map_reduce`, `subgraph`, etc.).

This cookbook entry currently provides reference coverage only; the fluent examples from GitBook depend on Composer chaining forms that are not yet verified as standalone runnable examples in this published `gllm-pipeline` version. Rather than ship fabricated wrappers, this entry defers to the source tutorial until the snippets are self-contained or a compatible API path is confirmed.

Reference:
    https://gdplabs.gitbook.io/sdk/gen-ai-sdk/tutorials/orchestration/composer
